# EV Cost Recovery GUI

Create a GUI binary `ev_cost_recovery` that implements the functionality of binary `cost_recovery_surplus_cli`. The new binary should have look-and-feel similar to that of `ev_peak_contrib`.

At this time, `ev_cost_recovery` will perform only one function, but later it will be expanded to include several functions to support data review and analysis, including the functionality similar to that currently in `ev_peak_contrib`. The design and implementation of `ev_cost_recovery` should anticipate this planned future expansion.
